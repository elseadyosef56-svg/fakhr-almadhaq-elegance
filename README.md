# Fakhir Almadhaq Prestige

أريد إنشاء موقع إلكتروني احترافي وفاخر لشركة فخر المذاق لاستيراد المواد الغذائية والمواشي واللحوم، باستخدام HTML وCSS وJavaScript فقط، بدون أي Frameworks أو مكتبات خارجية، ليكون جاهزًا للنشر مباشرة على GitHub Pages.
الموقع يتكون من صفحتين فقط:
1. الصفحة الرئيسية
شعار شركة فخر المذاق بتصميم فاخر واحترافي.
اسم الشركة بشكل واضح وأنيق.
نبذة تعريفية عن الشركة.
عرض مجالات وأنشطة الشركة:
استيراد السلع التموينية.
البقوليات.
المعلبات الغذائية.
المكسرات بأنواعها.
التوابل والبهارات.
المشروبات والعصائر.
الحليب ومنتجات الألبان.
الفواكه والشاي والبن والكاكاو.
البيض للاستهلاك.
استيراد لحوم الأبقار والأغنام والإبل الحية لغرض الذبح.
الأغنام والإبل والدواجن والأسماك المجمدة والمبردة.
الحيوانات الحية والطيور لغرض التربية.
تصميم بصري مستوحى من هوية الشعار: أخضر داكن + ذهبي فاخر.
واجهة حديثة، راقية، متجاوبة مع الهاتف والكمبيوتر.
حركات انتقالية ناعمة وتأثيرات احترافية بدون مبالغة.
